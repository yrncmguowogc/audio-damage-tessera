## Overview

Tessera is a four-channel panning and routing matrix plugin where each channel follows an independent trajectory through a virtual 2D field, creating evolving, polyrhythmic spatial motion.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Audio Damage Tessera** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Quad Panning** | Four independent panning voices moving on configurable XY trajectories |
| **Polyrhythm** | Per-voice LFO rates with polyrhythmic relationships for complex motion |
| **Trajectory Editor** | Visual XY path editor with bezier curve control per voice |
| **Binaural Output** | HRTF-based binaural processing for headphone spatial rendering |
